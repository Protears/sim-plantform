# IW.SIM 空间关系模型设计

## 1. 设计目标

空间模型用于描述自动化场景中的几何关系、拓扑关系和运行约束。

## 2. 核心对象

包括：

- Area 区域
- Aisle 巷道
- Rack 货架
- Bay 货位列
- Level 层
- Depth 深度
- Place 存储位置
- Track 运行轨迹

## 3. 空间关系

空间关系包括：

- 包含关系
- 相邻关系
- 连接关系
- 可达关系

## 4. 应用场景

空间模型支撑：

- 设备定位
- 路径规划
- 货物追踪
- 三维可视化
- 碰撞检测

## 5. 工业场景映射

例如立库：

Rack -> Bay -> Level -> Depth -> Place

形成统一货位空间体系。
