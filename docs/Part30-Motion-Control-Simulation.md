# IW.SIM Part30 - Motion Control Simulation

## Overview

运动控制仿真用于模拟工业设备动力学行为。

## Model

包含：

- Position
- Velocity
- Acceleration
- Motion Profile
- Limit Sensor

## Control

支持：

- Position Control
- Speed Control
- Servo Simulation

## Integration

Motion Runtime 与 PLC Runtime、Device Runtime 集成，实现机电控一体化仿真。
