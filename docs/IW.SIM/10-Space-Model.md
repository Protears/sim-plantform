# Space Model

## Overview
IW.SIM Space Model describes industrial physical environments and their topology.

## Core Concepts

- Space
- Area
- Aisle
- Rack
- Bay
- Level
- Depth
- Place
- Track

## Unified Spatial Representation

The model supports:

- Storage systems
- Conveyor layouts
- Robot navigation spaces
- Device working zones

## Spatial Relationship

Entities maintain geometric position, topology connection and operational constraints.

## Benefits

Provides a common foundation for visualization, path planning, collision detection and simulation execution.
