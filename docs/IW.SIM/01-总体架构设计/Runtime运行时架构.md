# IW.SIM Runtime运行时架构设计

## 1. 概述

Simulation Runtime 是 IW.SIM 的核心执行引擎，负责驱动仿真世界持续演化。

## 2. 核心组件

### SimClock

负责仿真时间管理。

支持：

- 实时时钟模式；
- 加速模式；
- 离散时间推进。

### Event Scheduler

负责事件排序和执行。

事件包括：

- 设备动作完成；
- 传感器触发；
- PLC信号变化；
- 任务状态变化。

### Behavior Engine

执行设备行为逻辑。

例如：

- 输送机运动；
- 堆垛机升降；
- RGV行走；
- 货载状态变化。

## 3. 执行流程

```
时间推进
 ↓
事件获取
 ↓
行为执行
 ↓
状态更新
 ↓
消息发布
 ↓
下一周期
```

## 4. 确定性设计

Runtime保证：

- 固定事件顺序；
- 可重复执行；
- 可记录和回放。

这为自动测试、故障分析和虚拟调试提供基础。
