# IW.SIM Engineering Platform

## Overview
IW.SIM Engineering Platform is the industrial simulation engineering environment for logistics automation systems. It integrates modeling, simulation, PLC integration, commissioning validation and engineering lifecycle management.

## Goals
- Unified engineering model for warehouse automation
- Support device simulation and control verification
- Provide reusable scene, device and protocol assets
- Enable virtual commissioning

## Platform Layers

### Project Layer
Manages projects, versions, environments and engineering artifacts.

### Modeling Layer
Provides equipment models, industrial thing models, spatial models and behavior definitions.

### Simulation Layer
Provides discrete event simulation, real-time simulation and deterministic execution.

### Integration Layer
Supports PLC, WCS, MES and external control systems.

## Technology Foundation
- .NET 10 / C# 13
- ASP.NET Core
- PostgreSQL
- Vue 3 + PixiJS
- OpenTelemetry observability

## Engineering Workflow
Requirement -> Modeling -> Configuration -> Simulation -> Virtual Commissioning -> Deployment Validation
