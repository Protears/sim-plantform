# IW.SIM Deployment Architecture

## Deployment Model

Supports local engineering deployment, server deployment and containerized deployment.

## Components

- Web Entry
- Simulation Runtime
- Model Service
- Database
- Message and Monitoring Services

## Containerization

Docker Compose is supported for standard environments.

## Requirements

- Stable long-running execution
- Internal network deployment
- Configurable environments

## Operations

Includes version management, backup, monitoring and diagnostics.
