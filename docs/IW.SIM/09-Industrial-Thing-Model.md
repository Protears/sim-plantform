# Industrial Thing Model

## Concept
Industrial Thing Model defines the digital representation of physical industrial entities in IW.SIM.

## Core Elements

- Thing: industrial entity abstraction
- Capability: supported functions and behaviors
- Property: state and configuration data
- Service: executable operations
- Event: state changes and notifications

## Model Hierarchy

Thing Model -> Device Model -> Runtime Instance -> Simulation Entity

## Design Principles

- Domain driven design
- Runtime extensibility
- Protocol independent abstraction
- Physical and virtual consistency

## Application

Used for conveyors, stacker cranes, RGV, AGV, PLC controlled devices and warehouse infrastructure.
