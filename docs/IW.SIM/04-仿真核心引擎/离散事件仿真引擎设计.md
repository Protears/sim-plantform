# IW.SIM 离散事件仿真引擎设计

## 1. 概述

IW.SIM采用离散事件驱动（Discrete Event Simulation, DES）作为核心仿真机制，通过事件推进工业世界状态演化。

与连续物理仿真不同，物流自动化系统主要关注设备动作、控制信号、任务变化和货物流转等离散过程。

## 2. 核心思想

仿真系统不按照固定物理时间计算所有对象，而是按照事件发生顺序推进仿真时间。

核心流程：

```
事件产生
 ↓
事件进入队列
 ↓
按照时间排序
 ↓
执行事件处理器
 ↓
更新世界状态
 ↓
产生后续事件
```

## 3. 事件模型

事件包含：

- EventId
- EventType
- ExecuteTime
- Source
- Payload
- Handler

典型事件：

- 电机启动完成
- 输送机货物到位
- 传感器触发
- PLC输出变化
- WCS任务状态变化

## 4. 设计目标

- 保证确定性执行；
- 支持时间加速；
- 支持事件回放；
- 支持大规模设备仿真。

## 5. 工业应用

该引擎支撑输送机、RGV、堆垛机、AGV以及WCS调度系统的闭环仿真。
