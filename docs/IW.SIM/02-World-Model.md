# Chapter 02 - World Model

## Industrial World Model

World Model represents the complete simulated industrial environment.

## Core Entities

- World
- Scene
- Space
- Place
- LoadUnit
- Cargo
- Device
- Sensor
- Controller
- Resource

## Object Relationship

World contains spaces and entities. Entities expose state, capability and behavior.

## Modeling Principles

- Unified spatial model
- Physical entity abstraction
- Runtime state separation
- Event based state changes
