# IW.SIM 工业物模型总体设计

## 1. 概述

工业物模型（Industrial Thing Model）是 IW.SIM 对工业对象进行统一数字化描述的核心模型。

与传统设备模型不同，Thing Model关注工业对象的能力、状态、行为以及与外部系统交互方式。

## 2. 模型定位

Thing Model 位于物理设备和仿真运行时之间：

```
物理设备
   ↓
Thing Model
   ↓
Simulation Runtime
   ↓
控制系统
```

## 3. 核心组成

- Thing：工业对象
- Property：属性
- Capability：能力
- Service：服务
- Event：事件

## 4. 设计原则

### 设备与能力分离

设备是能力的载体，能力定义设备可以完成什么。

### 面向行为建模

模型不仅保存数据，还描述运行过程。

### 支持扩展

新增设备类型无需修改核心引擎。

## 5. 应用范围

支持：

- 输送机
- RGV
- 堆垛机
- AGV
- PLC控制设备
- 传感器
