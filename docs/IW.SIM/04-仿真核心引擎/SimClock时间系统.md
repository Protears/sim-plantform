# IW.SIM SimClock时间系统设计

## 1. 概述

SimClock负责管理仿真世界中的时间，是保证系统确定性运行的基础。

## 2. 时间模式

支持：

- 实时时间模式；
- 加速仿真模式；
- 单步调试模式；
- 自动回放模式。

## 3. 时间推进

仿真时间不直接依赖操作系统时间，而由Runtime统一控制。

```
SimTime
 ↓
EventScheduler
 ↓
Behavior执行
 ↓
State变化
```

## 4. 设计要求

- 时间可控；
- 状态可重现；
- 问题可定位；
- 测试可自动化。

## 5. 应用场景

支持PLC联调、WCS算法验证以及故障复现。
