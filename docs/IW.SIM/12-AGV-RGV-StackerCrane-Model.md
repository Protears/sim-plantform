# AGV RGV Stacker Crane Model

## Overview
IW.SIM provides unified equipment models for warehouse automation devices.

## Equipment Types

### AGV
Autonomous transport equipment with navigation, task execution and traffic management.

### RGV
Rail guided vehicle model supporting track movement, positioning and PLC control.

### Stacker Crane
Three dimensional storage equipment supporting vertical, horizontal and depth movement.

## Common Model

All equipment implements:

- State model
- Motion model
- Capability model
- Control interface
- Fault model

## Integration

Supports WCS scheduling simulation and PLC virtual commissioning.
