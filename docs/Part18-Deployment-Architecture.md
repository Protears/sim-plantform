# IW.SIM Part18 - Deployment Architecture

## Overview

IW.SIM supports flexible deployment from development environment to production simulation clusters.

## Deployment Modes

- Desktop Simulation
- Server Simulation
- Distributed Simulation
- Cloud Simulation

## Runtime Deployment

Components:

- Web Gateway
- Simulation Service
- Device Runtime Host
- PLC Runtime Host
- Database
- Observability Stack

## Containerization

Support:

- Docker
- Docker Compose
- Kubernetes

## Reliability

Features:

- Health Check
- Service Recovery
- Log Collection
- Metrics Monitoring
