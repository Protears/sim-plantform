# 堆垛机设备仿真模型设计

## 1. 概述

堆垛机是自动化立库核心三维运动设备。IW.SIM通过运动轴模型、货叉模型和控制模型实现真实行为仿真。

## 2. 三轴运动模型

支持：

- X轴水平行走
- Y轴升降运动
- Z轴伸叉运动

每个轴包含：

- 当前位置
- 目标位置
- 速度
- 加速度
- 限位
- 状态

## 3. 货叉模型

货叉支持：

- 伸出
- 缩回
- 取货
- 放货
- 位置校验

## 4. 控制接口

通过PLC映射：

- 运行指令
- 位置反馈
- 原点信号
- 限位信号
- 故障信号

## 5. 仿真价值

支持立库方案验证、PLC程序调试以及WCS任务联调。
