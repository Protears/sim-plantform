# 设备状态机设计

## 1. 设计目标

统一描述IW.SIM中工业设备的生命周期、运行状态和异常处理。

## 2. 基础状态

```
Created
 ↓
Idle
 ↓
Ready
 ↓
Running
 ↓
Completed
```

## 3. 异常状态

包括：

- Warning
- Fault
- EmergencyStop
- Offline
- Maintenance

## 4. 状态转换原则

设备状态变化必须通过事件驱动，而不是直接修改。

```
Command
 ↓
Behavior
 ↓
Event
 ↓
State Change
```

## 5. 应用

该模型被Conveyor、RGV、堆垛机、AGV等设备统一继承。
