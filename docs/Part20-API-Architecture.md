# IW.SIM Part20 - API Architecture

## Overview

IW.SIM API provides unified access between frontend, simulation services and external systems.

## API Layers

- Gateway API
- Domain API
- Runtime API
- Integration API

## Protocols

- REST API
- SignalR
- WebSocket
- Event API

## Design Rules

- URL Versioning
- JSON camelCase
- Resource Oriented Design
- OpenAPI Documentation

## Integration

Supports WCS, MES, PLC simulation and digital twin systems.
