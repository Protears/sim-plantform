# IW.SIM 世界模型总体设计

## 1. 概念

世界模型（World Model）是 IW.SIM 对工业现场环境的统一数字化描述。

它不仅描述设备的位置，还描述设备之间的关系、状态以及运行过程。

## 2. 核心对象

### WorldEntity

所有仿真实体的基础对象。

包含：

- Identity
- Position
- State
- Relations
- Behaviors

### Space Model

描述工业空间：

- 区域
- 巷道
- 货架
- 输送线路
- 设备轨迹

### Device Model

描述设备实例及运行状态。

## 3. 状态管理

世界模型维护：

- 当前状态；
- 历史状态；
- 事件变化；
- 观察数据。

## 4. 设计价值

世界模型为：

- 仿真运行；
- 三维展示；
- 路径规划；
- 数字孪生；
- 故障分析

提供统一基础。
