# Conveyor运动学模型设计

## 1. 设计目标

输送机运动模型用于模拟货载在输送过程中的连续运动状态。

## 2. 运动参数

统一采用工业单位：

- 速度：m/s
- 加速度：m/s²
- 距离：m

## 3. 运动模型

支持：

### 匀速运动

货载按照设定速度持续移动。

### 匀加速运动

根据初速度、加速度和时间计算位置变化。

公式：

```
s = v0*t + 0.5*a*t²
```

## 4. 状态更新

每个仿真周期：

```
SimClock Tick
 ↓
计算位移
 ↓
更新Cargo位置
 ↓
检测Sensor
 ↓
触发Event
```

## 5. 工业一致性

运动模型需要保证：

- PLC反馈周期一致；
- 传感器触发准确；
- 货载跟踪连续。
