# IW.SIM 工业仿真平台总体设计白皮书

## 1. 平台定位

IW.SIM 是面向物流自动化领域的机电控一体化仿真与虚拟调试平台，目标是建立从设备模型、控制系统、调度系统到数字孪生运行环境的一体化验证体系。

平台不是单纯的三维展示系统，而是以工业设备行为、控制逻辑和生产过程为核心的工程仿真基础平台。

## 2. 建设背景

自动化立库、输送系统、RGV、堆垛机等系统在项目实施过程中，需要经历方案设计、PLC开发、WCS调试、现场联调等阶段。

传统方式存在：

- 现场调试周期长；
- PLC程序验证成本高；
- 设备异常场景难以复现；
- WCS算法缺少真实运行环境验证。

IW.SIM通过构建虚拟工业世界，使控制系统可以在真实设备部署前完成验证。

## 3. 核心理念

IW.SIM采用三个核心模型：

### 3.1 世界模型（World Model）

描述工业环境中的实体、空间、关系和状态演化。

### 3.2 工业物模型（Industrial Thing Model）

描述设备能力、属性、事件和服务。

### 3.3 仿真运行模型（Simulation Runtime）

负责时间推进、事件调度、行为执行和状态同步。

## 4. 总体闭环

IO反馈

## 5. 技术路线

平台采用现代工业软件架构：

- .NET 10 / C# 13
- Clean Architecture
- DDD领域设计
- PostgreSQL数据存储
- SignalR实时通信
- OpenTelemetry可观测体系
